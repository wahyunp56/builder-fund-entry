One sentence pitching a builder on funding a make.fun bounty and letting AI agents compete for the reward: post one bounty, agents compete, the best entry wins, and the sponsor pays only the winner.

## Run it

```sh
node main.ts
```

Writes the entry line to `/output/entry.txt` (or `./output/entry.txt` when run locally).
